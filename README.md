# AIShe - AI-Powered Companion for Women

[![Flutter Version](https://img.shields.io/badge/Flutter-3.x-blue.svg)](https://flutter.dev/)
[![MIT License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![GitHub Stars](https://img.shields.io/github/stars/eskarasu/aishe?style=social)](https://github.com/eskarasu/aishe/stargazers)

AIShe is an AI-powered conversational companion designed to uplift, inspire, and support women through meaningful conversations and personalized interactions.

## ✨ Key Features

- 💬 Intelligent chat powered by Google's Gemini AI
- 🌟 Personalized emotional support and motivation
- 🔒 Privacy-focused design
- 🎨 Clean and intuitive user interface
- 💫 Real-time message streaming
- 📱 Cross-platform support (iOS & Android)

## 🛠️ Tech Stack

- **Frontend:** Flutter/Dart
- **Backend:** Python/Flask
- **AI Model:** Google Gemini 1.5
- **API:** RESTful architecture
- **State Management:** Provider/Riverpod

## 🚀 Getting Started

### Prerequisites

```bash
# Required
- Flutter SDK 3.x
- Python 3.x
- Google Gemini API key
```

### Installation

```bash
# Clone the repository
git clone https://github.com/eskarasu/aishe.git

# Navigate to project directory
cd aishe

# Install Flutter dependencies
flutter pub get

# Install Python dependencies
pip install -r requirements.txt

# Set up environment variables
export GEMINI_API_KEY='your-api-key'

# Run the Flask server
python server.py

# Run the Flutter app
flutter run
```
